## Food Direction Finder

这是一个简单的网页工具，通过旋转的指南针随机选择一个360度方向（0°-359°），帮你决定寻找食物的方向。

### 使用方法

1. 直接在浏览器中打开 `index.html` 文件。
2. 点击 "SPIN THE COMPASS" 按钮。
3. 指针会旋转并随机停在一个方向（如 NE (45°)、SW (225°) 等）。
4. 根据指示的方向和角度去寻找美食吧！

### 功能特点

- 美观的指南针界面，带有8个主要方向标记（N, NE, E, SE, S, SW, W, NW）
- 360度随机方向选择（0°-359°）
- 平滑的旋转动画
- 历史记录显示最近的旋转结果（包含角度）
- 响应式设计，适配各种屏幕尺寸

### 文件说明

- `index.html` - 主界面文件（包含所有 HTML、CSS 和 JavaScript）
- `readme.md` - 项目说明文件

### 技术细节

- 纯 HTML/CSS/JavaScript，无需安装任何依赖
- 使用 CSS 变换实现旋转动画
- 使用 requestAnimationFrame 实现平滑动画
- 数据存储在内存中（刷新页面会重置历史记录）
