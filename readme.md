# whatToEat

一个用指南针随机决定“往哪个方向找吃的”的静态网页工具。

## 今天往哪吃

页面会通过旋转指南针随机选择一个方向，适合在不知道往哪边走时快速做决定。它只选择方向，不随机食物类型。

## 使用方法

1. 直接在浏览器中打开 `index.html`。
2. 点击“转一下”。
3. 等指针停下后，根据页面显示的方向和角度去找吃的。
4. 可在设置里切换“360度随机”或“八方向随机”。

## 功能特点

- 中文界面和中文方向提示
- 360度随机方向选择，或八方向随机选择
- 可尽量避免连续两次得到同一方向
- 平滑旋转动画，并适配系统“减少动态效果”设置
- 最近 10 次历史记录，刷新页面后仍会保留
- 支持清空历史记录
- 响应式布局，适配手机和桌面屏幕
- 基础可访问性支持，包括结果区域播报和键盘焦点样式

## 文件说明

- `index.html` - 主界面文件，包含 HTML、CSS 和 JavaScript
- `readme.md` - 项目说明文件

## 技术细节

- 纯 HTML/CSS/JavaScript，无需安装依赖
- 使用 CSS 变换和 `requestAnimationFrame` 实现指针旋转
- 使用 `localStorage` 保存最近历史记录
